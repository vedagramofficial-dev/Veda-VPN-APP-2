# Как задавать версию APK VEDA VPN

При сборке через GitHub Actions можно задавать номер и название версии вручную.

1. Откройте репозиторий → **Actions**.
2. Выберите **Build VEDA VPN APK**.
3. Нажмите **Run workflow**.
4. Заполните:
   - `version_name` — видимая версия, например `0.3.1`, `0.4.0`.
   - `version_code` — целое число, которое нужно увеличивать при каждой новой сборке, например `4`, `5`, `6`.
5. Запустите workflow и скачайте APK из **Artifacts**.

Важно: `version_code` должен быть больше, чем у предыдущего APK, если вы хотите устанавливать обновление поверх старой версии. Если `version_code` повторяется или уменьшается, Android может отказать в установке обновления.

При обычном push в `main` используется значение по умолчанию из workflow. Для ручного выбора версии используйте **Run workflow**.
